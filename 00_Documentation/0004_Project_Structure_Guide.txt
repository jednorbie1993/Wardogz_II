===========================================================
FOLDER PURPOSES
===========================================================

-----------------------------------------------------------
00_Documentation
-----------------------------------------------------------

Purpose:
Stores all project documentation.

Examples:

- GitHub setup guide
- Raylib installation guide
- Git commands
- Project roadmap
- Development notes
- Future ideas
- Troubleshooting

Think of this folder as the project's manual.

-----------------------------------------------------------
.vscode
-----------------------------------------------------------

Purpose:
Stores Visual Studio Code configuration files.

Examples:

- tasks.json
- launch.json
- settings.json

These files allow easier building, debugging, and running
the project directly from VS Code.

No changes are required for now.

-----------------------------------------------------------
assets
-----------------------------------------------------------

Purpose:
Stores all game resources.

Subfolders:

sprites
    Player and NPC images.

enemies
    Enemy sprites.

background
    Maps and stage backgrounds.

music
    Background music.

sfx
    Sound effects.

fonts
    Custom fonts.

ui
    Buttons, icons, menus, and interface graphics.

Keeping assets organized makes future development much
easier.

-----------------------------------------------------------
build
-----------------------------------------------------------

Purpose:
Stores compiled output files.

Example:

build
    Wardogz_II.exe

Advantages:

- Keeps the root folder clean.
- Easy to locate compiled files.
- Separates source code from executable files.

-----------------------------------------------------------
include
-----------------------------------------------------------

Purpose:
Stores all header (.h) files.

Examples:

player.h
enemy.h
camera.h
collision.h
ui.h

This folder contains function declarations, structures,
constants, and shared definitions.

-----------------------------------------------------------
src
-----------------------------------------------------------

Purpose:
Stores all C source (.c) files.

Examples:

main.c
player.c
enemy.c
camera.c
battle.c
collision.c
ui.c

All game logic belongs here.

This is the standard structure used in most professional
C and C++ projects.

NEXT STEP
===========================================================

Current Location:

Wardogz_II
    main.c

Recommended Location:

Wardogz_II
    src
        main.c

Reason:

Professional C and C++ projects keep all source files
inside the "src" folder.

As the project grows (player.c, enemy.c, camera.c,
battle.c, collision.c, ui.c, etc.), the project remains
organized and much easier to maintain.
