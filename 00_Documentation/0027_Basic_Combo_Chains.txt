============================================================
TITLE
============================================================

0027_Basic_Combo_Chains

============================================================
PURPOSE
============================================================

Add the first real combo-recognition logic on top of the 0026
input buffer.

0026 remembers one next attack input.

0027 now recognizes one ordered attack sequence:

A -> W -> D

============================================================
COMBO
============================================================

A = Left Punch
W = Right Punch
D = Right Kick

Step 0:
No combo started.

Step 1:
A accepted.

Step 2:
A -> W accepted.

Step 3:
A -> W -> D completed.

============================================================
COMBO WINDOW
============================================================

COMBO_WINDOW = 0.70 seconds

If the next required attack is too slow, the combo resets.

============================================================
NEW PLAYER DATA
============================================================

int comboStep;
float comboTimer;
bool comboFinisherActive;

============================================================
IMAGES
============================================================

No new images are required.

0027 reuses the current Left Punch, Right Punch,
and Right Kick animations.
