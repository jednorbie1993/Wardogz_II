==========================================================
WARDOGZ II
GitHub Repository Setup Documentation
Date: August 3, 2026
==========================================================

Purpose:
To connect the Wardogz II project to GitHub so it can be backed up,
shared between computers, and updated easily.

----------------------------------------------------------
STEP 1 - Create GitHub Repository
----------------------------------------------------------

1. Log in to GitHub.
2. Click the "+" icon.
3. Select "New Repository".

Repository Name:
Wardogz_II

Visibility:
Public

Configuration:

[x] Public
[ ] Add README
[ ] Add .gitignore
[ ] Add License

Reason:
The project already exists on the computer.
README, .gitignore, and LICENSE can be added later.

----------------------------------------------------------
STEP 2 - Open Project Folder
----------------------------------------------------------

Open VS Code.

Open Folder:

Wardogz_II

Open Terminal.

----------------------------------------------------------
STEP 3 - Initialize Git
----------------------------------------------------------

Command:

git init

Result:

Initialized empty Git repository...

----------------------------------------------------------
STEP 4 - Check Git Status
----------------------------------------------------------

Command:

git status

Result:

On branch main

No commits yet

----------------------------------------------------------
STEP 5 - Create .gitignore
----------------------------------------------------------

Create file:

.gitignore

Contents:

*.exe
*.o
/build/
Thumbs.db

Purpose:

- Ignore executable files
- Ignore object files
- Ignore build folder
- Ignore Windows Thumbs.db

----------------------------------------------------------
STEP 6 - Remove Unnecessary Files
----------------------------------------------------------

Deleted:

Wardogz_II.exe
wardogz.exe

Reason:

Compiled files should not be uploaded to GitHub.

----------------------------------------------------------
STEP 7 - Stage Files
----------------------------------------------------------

Command:

git add .

Verify:

git status

Files staged:

.gitignore
assets/player.png
how to run.txt
main.c

----------------------------------------------------------
STEP 8 - First Commit
----------------------------------------------------------

Command:

git commit -m "Initial commit"

Commit ID:

8d6223e

Result:

Initial commit created successfully.

----------------------------------------------------------
STEP 9 - Connect to GitHub
----------------------------------------------------------

Repository URL:

https://github.com/jednorbie1993/Wardogz_II.git

Command:

git remote add origin https://github.com/jednorbie1993/Wardogz_II.git

Verify:

git remote -v

Output:

origin (fetch)
origin (push)

----------------------------------------------------------
STEP 10 - Upload to GitHub
----------------------------------------------------------

Command:

git push -u origin main

Result:

Branch uploaded successfully.

Current branch:

main

Remote:

origin/main

----------------------------------------------------------
Future Workflow
----------------------------------------------------------

Every time changes are made:

git status
git add .
git commit -m "Describe your changes"
git push

Example:

git commit -m "Added player movement"

git push

----------------------------------------------------------
Notes
----------------------------------------------------------

Commands below are only executed ONCE:

git init

git remote add origin ...

git push -u origin main

After the initial setup,
only use:

git add .
git commit
git push
