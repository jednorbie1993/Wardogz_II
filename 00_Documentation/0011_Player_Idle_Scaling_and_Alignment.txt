DOCUMENTATION 0011

TITLE:
Player Idle, Scaling, Alignment, and Sprite Image Adjustments

===========================================================
OVERVIEW
===========================================================

This document records the player sprite/image system used for Jamber,
including idle animation, image sizing, depth scaling, bottom alignment,
and later visual sprite adjustments.

The player image files can be replaced or redrawn without changing the
gameplay collision rectangle, as long as DrawPlayer continues to use the
current texture dimensions and the same bottom-center anchor system.

===========================================================
1. PLAYER IDLE ANIMATION
===========================================================

The original idle animation uses 3 frames:

idle_1.png
idle_2.png
idle_3.png

idle_4.png was removed.

The currently active idle texture is selected using the player's
idle animation frame.

The drawing system uses the dimensions of the current texture instead
of assuming every image has exactly the same source size.

This prevents sprite cropping when newer player images use a larger
canvas.

===========================================================
2. SPRITE IMAGE SIZE VS GAMEPLAY RECTANGLE
===========================================================

The visible Jamber sprite can use a larger image/canvas than the
Player rectangle.

The player rectangle is mainly used for gameplay positioning,
movement, collision, hurtboxes, and related calculations.

The sprite image is drawn separately over that rectangle.

Because of this, changing the PNG canvas or visible character size
does NOT require making the Player rectangle the same size as the PNG.

===========================================================
3. DEPTH / PERSPECTIVE SCALING
===========================================================

Player size changes depending on vertical position in the walk area.

Current reference range:

Top Y    = 270
Bottom Y = 700

Depth is calculated from the player's Y position.

Current scaling reference:

scale = 2.70 + (depth * 1.80)

Width also uses an additional multiplier:

width *= 1.30

Result:

- Jamber appears smaller farther toward the top/back of the stage.
- Jamber appears larger toward the bottom/front of the stage.
- The effect gives the beat-'em-up stage a depth/perspective feeling.

===========================================================
4. BOTTOM-CENTER SPRITE ALIGNMENT
===========================================================

The sprite uses bottom-center alignment.

This is important because sprite images can have different canvas
sizes while the player's feet still stay attached to the same gameplay
position.

General idea:

destination.x =
    player center X - half of the scaled sprite width

destination.y =
    player bottom Y - scaled sprite height

The feet/bottom of the image are therefore treated as the visual anchor.

===========================================================
5. PLAYER IMAGE / SPRITE ADJUSTMENTS
===========================================================

The Jamber images have been updated several times after the original
idle system was created.

Current visual direction:

- White dog head
- Black tactical vest
- Muscular brown arms with white patches
- Olive cargo pants
- Black combat boots
- Retro pixel-art fighting-game appearance
- Classic arcade / KOF-like visual texture
- Character should NOT look chubby
- Keep the body muscular and balanced

Recent image adjustments:

- Slightly larger head than the earlier version
- Character height slightly reduced visually
- Keep proportions consistent between animation frames
- Deeper/slightly darker shading
- Preserve visible pixel texture and highlights
- Keep full body visible
- Maintain enough transparent canvas space around the character
- Keep feet aligned consistently between frames

These are IMAGE adjustments only unless a code change is specifically
needed for alignment or animation.

- Left foot forward

- Do not unnecessarily redesign the character
- Slightly darker overall shading

===========================================================
7. WHY CURRENT TEXTURE DIMENSIONS ARE IMPORTANT
===========================================================

Newer Jamber sprites do not always use the exact same canvas dimensions
as older images.

DrawPlayer must therefore continue to derive the source image width
and height from the currently selected texture.

This lets us improve or replace:

- idle images
- idle breathing images
- battle idle images
- walk images
- punch images
- kick images

without forcing every PNG to use the old exact image dimensions.

===========================================================
8. IMAGE REPLACEMENT RULE
===========================================================

When replacing a Jamber PNG:

1. Keep the full body inside the transparent canvas.
2. Do not crop the ears, head, hands, or boots.
3. Keep the feet near a consistent bottom reference.
4. Preserve the intended facing direction.
5. Keep Jamber's proportions consistent.
6. Do not make the character chubby.
7. Preserve the retro pixel-art texture.
8. Check the sprite in-game after replacement.
9. Adjust draw offset only when the new image genuinely needs it.
10. Do not change the gameplay rectangle only because the PNG canvas
    became larger.
