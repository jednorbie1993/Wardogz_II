TITLE:
Vargas Boss Integration / Battle Idle Test System


PURPOSE
-------
Adds Vargas as the first Stage 1 Boss enemy and tests his complete sprite set
inside the existing shared Enemy system.

For this initial integration test:

- Punk is temporarily hidden
- Hooligan is temporarily hidden
- Gangster is temporarily hidden
- Vargas is the only active enemy
- no final-meter Boss trigger yet
- no loading screen yet
- no Boss phases yet

The first goal is to confirm that Vargas can appear, move, attack, change
stance, receive damage, and play his death animation correctly.

---------

    VARGAS

The enemy HUD displays:

    VARGAS


VARGAS SPRITE LOCATION
----------------------
All Vargas sprite files are stored in:

    assets/sprites/enemy/stage_1/boss/


NORMAL IDLE
-----------
Before Vargas performs his first attack, he uses:

    boss_idle1.png
    boss_idle2.png


BATTLE IDLE
-----------
After Vargas starts his first punch or kick, his battle stance becomes active.

Battle idle files:

    boss_battle_idle1.png
    boss_battle_idle2.png
    boss_battle_idle3.png
    boss_battle_idle4.png

Behavior:

    Vargas starts in normal idle
    -> Vargas performs his first attack
    -> battleIdleActive becomes true
    -> Vargas uses battle idle after attacks
    -> Vargas does not return to normal idle during the encounter

The battle idle state is optional in the shared Enemy structure.

Punk, Hooligan, and Gangster have:

    battleIdleFrameCount = 0

Therefore, they continue using their normal idle animations and are not
affected by Vargas' battle-idle system.

DEATH ANIMATION
---------------
Vargas uses four death frames:

    boss_death1.png
    boss_death2.png
    boss_death3.png
    boss_death4.png

The common frame capacity was updated from:

    #define MAX_ENEMY_DEATH_FRAMES 3

to:

    #define MAX_ENEMY_DEATH_FRAMES 4

This prevents an out-of-bounds texture-array write and safely supports Vargas'
four-frame death animation.

SHARED TEXTURE CACHE
--------------------

visual/gameplay test.

On-demand loading at the final stage meters will be implemented separately
after this test is stable.

=========================================================
FUTURE FEATURE FILE GUIDE
=========================================================

The following guide records which files should normally be changed when
adding future Vargas features.


NEW MOVE / NEW ATTACK ANIMATION
-------------------------------
Example:

    boss_uppercut1.png
    boss_uppercut2.png
    boss_uppercut3.png
    boss_uppercut4.png

Files normally involved:

    include/enemy/enemy.h
    src/enemy/enemy_attack.c
    src/enemy/enemy_draw.c
    src/enemy/stage_1/boss.c

Responsibilities:

enemy.h:

    - new move state/type
    - texture array
    - frame count
    - timers or flags

enemy_attack.c:

    - attack activation
    - frame timing
    - damage timing
    - hitbox activation
    - move transition

enemy_draw.c:

    - choose the correct move texture

boss.c:

    - load/unload the Vargas PNG files
    - assign Vargas-specific frame counts
    - set range, damage, hitbox, and timing values


EXISTING ATTACK IMAGE OR STAT CHANGE
------------------------------------
If only replacing Vargas' existing punch/kick images:

    src/enemy/stage_1/boss.c

If changing attack speed, damage, range, or hitbox:

    src/enemy/stage_1/boss.c

If one attack frame needs special timing or movement:

    src/enemy/enemy_attack.c


STATS ONLY
----------
Examples:

- HP
- damage
- chase speed
- attack range
- retreat speed
- sprite size
- sprite alignment

Primary file:

    src/enemy/stage_1/boss.c

SHARED SYSTEM SAFETY RULE
-------------------------
These files are shared by all enemy types:

    enemy_move.c
    enemy_animation.c
    enemy_attack.c
    enemy_draw.c

Changing shared logic can affect:

    Punk
    Hooligan
    Gangster
    Vargas

Boss-only behavior should therefore use an optional state, flag, or enemy-type
check so normal enemies are not accidentally changed.

The 0061 battle-idle system follows this rule:

    Vargas has battleIdleFrameCount = 4
    normal enemies have battleIdleFrameCount = 0

Therefore, only Vargas activates and displays the new battle idle.
