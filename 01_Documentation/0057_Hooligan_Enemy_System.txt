TITLE:
Hooligan Enemy Type / Sprite Integration System


PURPOSE
-------
Adds Hooligan as a separate Stage 1 enemy type while continuing to use the
shared Enemy AI, movement, collision, attack, damage, and drawing systems.

The Hooligan is not another Punk instance. It has its own:

- display name
- HP and movement settings
- sprite texture cache
- idle animation
- run animation
- punch animation
- kick animation
- death animation
- sprite size and alignment settings

SHARED TEXTURE CACHE
--------------------
The Hooligan textures are loaded only once through:

    LoadHooliganSharedTextures();

All Hooligan instances reuse the same loaded Texture2D handles.

They are released once during shutdown through:

    UnloadHooliganSharedTextures();

This follows the same shared-texture design already used by Punk and avoids
loading duplicate copies when multiple Hooligans exist.


ATTACK COMPATIBILITY
--------------------
The common Enemy system currently names its second attack slot:

    ENEMY_ATTACK_ELBOW

For Hooligan, the same internal slot displays the four kick frames.

Concept:

    common punch slot -> Hooligan punch
    common elbow slot -> Hooligan kick

This allows Hooligan to use a kick without duplicating the entire shared enemy
attack system.


HOOLIGAN INITIALIZATION
-----------------------
Hooligan instances are created through:

    Enemy InitHooligan(float x, float y);

The initializer begins with:

    Enemy enemy = InitEnemyBase();

It then applies Hooligan-specific values, including:

    enemy.displayName = "HOOLIGAN";
    enemy.maxHp = 14;
    enemy.chaseSpeed = 180.0f;
    enemy.idleFrameCount = 3;
    enemy.walkFrameCount = 6;
    enemy.punchFrameCount = 4;
    enemy.elbowFrameCount = 4;
    enemy.deathFrameCount = 2;
