TITLE:
Gangster Enemy Type / Sprite Integration System


PURPOSE
-------
Adds Gangster as another separate Stage 1 enemy type with its own sprites,
stats, shared texture cache, animation counts, and display name.

Gangster uses the common Enemy systems instead of requiring duplicate AI,
collision, animation, attack, hit, and draw code.

SHARED TEXTURE CACHE
--------------------
Gangster textures are loaded once through:

    LoadGangsterSharedTextures();

They are released once during shutdown through:

    UnloadGangsterSharedTextures();

The runtime log confirmed that all Gangster files loaded successfully as
1024 x 1024 textures.

The loaded Gangster texture IDs covered:

    ID 82 through ID 101


ATTACK COMPATIBILITY
--------------------
The common second-attack slot is also reused for Gangster's kick animation:

    common punch slot -> Gangster punch
    common elbow slot -> Gangster kick


GANGSTER INITIALIZATION
-----------------------
Gangster instances are created through:

    Enemy InitGangster(float x, float y);

The initializer begins with:

    Enemy enemy = InitEnemyBase();

It then applies Gangster-specific values, including:

    enemy.displayName = "GANGSTER";
    enemy.maxHp = 18;
    enemy.chaseSpeed = 175.0f;
    enemy.idleFrameCount = 3;
    enemy.walkFrameCount = 6;
    enemy.punchFrameCount = 4;
    enemy.elbowFrameCount = 4;
    enemy.deathFrameCount = 3;
