0033 - Enemy Depth Scaling System

Date: 2026-08-11

============================================================
TITLE
============================================================

0033_Enemy_Depth_Scaling_System

============================================================
PURPOSE
============================================================

Add proper depth-based perspective scaling to the Punk enemy.

Before 0033:
- Punk movement and chase worked.
- Punk stayed the same visual size at TOP, MIDDLE, and BOTTOM.
- Early 0033 attempt scaled only the sprite image.
- The blue hurtbox and other combat boxes did not scale together.

After 0033:
- Punk becomes smaller toward the TOP/back area.
- Punk becomes larger toward the BOTTOM/front area.
- The enemy sprite and gameplay boxes use the same depth-scaling system.
- The Punk behaves like one complete character unit instead of a scaled image with fixed boxes.

============================================================
PLAYER REFERENCE
============================================================

0033 follows the same overall depth-scaling approach already used by the Player.

Player depth is calculated from the character's Y position.

The depth value is clamped between:

0.0f
and
1.0f

Then a perspective scale is calculated.

Existing Player-style scale:

scale =
2.90f +
(depth * 1.80f)

Meaning:

TOP / BACK
- smaller character

MIDDLE
- medium character

BOTTOM / FRONT
- larger character

============================================================
ENEMY DEPTH SOURCE
============================================================

The Punk uses its logical ground/stage position to calculate depth.

The enemy base hurtbox remains the logical position source.

A scaled enemy hurtbox is generated from:

- base enemy hurtbox
- current stage depth
- perspective scale

This avoids permanently changing the logical/base enemy rectangle.

============================================================
SCALED ENEMY SYSTEMS
============================================================

The following parts now use the same enemy perspective scaling:

1. Punk Sprite

The visible Punk image scales with depth.

TOP:
smaller sprite

BOTTOM:
larger sprite


2. Enemy Hurtbox

The BLUE enemy body hurtbox scales together with the sprite.

The hurtbox is no longer fixed while the image grows.


3. Enemy Foot / Ground Marker

The ORANGE foot marker follows the scaled enemy body.

This keeps the enemy depth reference aligned with the scaled Punk.


4. Enemy Attack Hitbox

The YELLOW attack hitbox follows the scaled enemy body and attack position.

This prevents the enemy attack box from remaining too small while the Punk sprite becomes larger.


5. Player -> Enemy Collision

Player attacks now check collision against the scaled enemy hurtbox.

This keeps visible enemy size and actual hittable area consistent.


6. Enemy HP Bar / Debug Position

Enemy debug and HP display positions follow the scaled enemy body area.

============================================================
IMPORTANT DESIGN RULE
============================================================

Sprite scaling alone is NOT enough.

Correct rule:

Punk Sprite
+
Enemy Hurtbox
+
Foot Marker
+
Attack Hitbox
+
Collision Checks

must use the same depth/perspective reference.

They should behave as one character system.
