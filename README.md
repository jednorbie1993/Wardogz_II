# Wardogz II

Wardogz II is a 2D beat 'em up game developed in C using the raylib game programming library.

Inspired by classic arcade games such as:

* Double Dragon
* Final Fight
* Streets of Rage
* Teenage Mutant Ninja Turtles
* Tekken Force Mode

The goal of the project is to create a modern beat 'em up while improving programming skills in C and game development.

---

## Features

Current and planned features include:

* Player movement
* Walking and idle animations
* Player attack system
* Attack hitboxes
* Enemy hurtboxes
* Enemy AI
* Enemy movement and tracking
* Enemy attack system
* Hit reaction and knockback
* Depth-based character scaling
* Combo attacks
* Grab and throw mechanics
* Boss battles
* Large scrolling maps
* Camera system
* Character progression
* Save and Load system
* Sound effects and music
