# 🐶 Wardogz II

Wardogz II is a 2D beat 'em up game developed in C using the raylib game programming library.

Inspired by classic arcade games such as:

- Double Dragon
- Final Fight
- Streets of Rage
- Teenage Mutant Ninja Turtles
- Tekken Force Mode

The goal of the project is to create a modern beat 'em up while improving programming skills in C and game development.

---

## Features (Planned)

- Player movement
- Camera system
- Large scrolling maps
- Enemy AI
- Combo attacks
- Grab and throw mechanics
- Boss battles
- Character progression
- Save & Load system
- Sound effects and music
