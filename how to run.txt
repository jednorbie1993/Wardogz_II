WARDOGZ II - HOW TO RUN
Updated: 2026-08-10

===========================================================
STEP 1 - OPEN PROJECT FOLDER
===========================================================

Open this folder in VS Code:

Wardogz_II


===========================================================
STEP 2 - BUILD AND RUN
===========================================================

Recommended command:

.\build_and_run.bat

This will:
1. Compile the game.
2. Compile player.c and the player modules.
3. Compile enemy.c and the enemy modules.
4. Compile the Stage 1 punk.c.
5. Create Wardogz_II.exe.
6. Run the game automatically.


===========================================================
STEP 3 - BUILD ONLY
===========================================================

If you only want to compile the game, run:

.\build.bat

If successful, the executable will be created here:

build\Wardogz_II.exe


===========================================================
STEP 4 - RUN THE GAME
===========================================================

If the game is already compiled, run:

.\build\Wardogz_II.exe


===========================================================
STEP 5 - RUN USING RUN.BAT
===========================================================

You can also run:

.\run.bat

This runs the existing:

build\Wardogz_II.exe

===========================================================
ENEMY SYSTEM STRUCTURE
===========================================================

enemy.c / enemy.h
= Shared base/orchestrator for ALL enemies.

enemy_move.c
= Enemy movement, chase AI, entrance, and stage boundary logic.

enemy_animation.c
= Shared idle and walk animation logic.

enemy_attack.c
= Enemy attack state, Punk punch/elbow attack flow, and attack hitbox.

enemy_hit.c
= Enemy damage, hit reaction, knockback, and death handling.

enemy_collision.c
= Enemy depth scaling, scaled hurtbox, foot marker, and collision/depth checks.

enemy_draw.c
= Shared enemy sprite drawing, debug boxes, attack hitbox display, and HP bar.

enemy_internal.h
= Internal shared declarations used by the enemy modules.


punk.c / punk.h
= Stage 1 Punk settings.

Contains:
- Punk idle textures
- Punk walk textures
- Punk Punch textures: punkp1.png - punkp4.png
- Punk Elbow textures: PUNKE1.png - PUNKE4.png
- Punk sprite size
- Punk sprite alignment
- Punk hurtbox size
- Punk HP/settings
