WARDOGZ II - HOW TO RUN
Updated: 2026-08-10

===========================================================
STEP 1 - OPEN PROJECT FOLDER
===========================================================

Open this folder in VS Code:

Wardogz_II


===========================================================
STEP 2 - BUILD AND RUN
===========================================================

Recommended command:

.\build_and_run.bat

This will:
1. Compile the game.
2. Compile player.c.
3. Compile the shared enemy.c.
4. Compile the Stage 1 punk.c.
5. Create Wardogz_II.exe.
6. Run the game automatically.


===========================================================
STEP 3 - BUILD ONLY
===========================================================

If you only want to compile the game, run:

.\build.bat

If successful, the executable will be created here:

build\Wardogz_II.exe


===========================================================
STEP 4 - RUN THE GAME
===========================================================

If the game is already compiled, run:

.\build\Wardogz_II.exe


===========================================================
STEP 5 - RUN USING RUN.BAT
===========================================================

You can also run:

.\run.bat

This runs the existing:

build\Wardogz_II.exe

===========================================================
ENEMY SYSTEM STRUCTURE
===========================================================

enemy.c / enemy.h
= Shared system for ALL enemies.

Contains:
- Damage
- HP
- HP bar
- Hurtbox
- Hit detection
- Hit reaction
- Knockback
- Death
- Common animation logic
- Common sprite drawing


punk.c / punk.h
= Stage 1 Punk settings.

Contains:
- Punk textures
- Punk sprite size
- Punk sprite alignment
- Punk hurtbox size
- Punk HP/settings
