===========================================================
            HOW TO RUN - WARDOGZ II
===========================================================

Project:
Wardogz II

Language:
C

Graphics Library:
raylib

===========================================================
STEP 1 - OPEN THE PROJECT
===========================================================

1. Open Visual Studio Code.

2. Click:

    File
        Open Folder...

3. Select:

    Wardogz_II

===========================================================
STEP 2 - OPEN THE TERMINAL
===========================================================

Click:

    Terminal
        New Terminal

or press

    Ctrl + `

===========================================================
STEP 3 - COMPILE THE PROJECT
===========================================================

Run the following command:

gcc src/main.c src/player.c src\enemy.c -o build/Wardogz_II.exe ^
-Iinclude ^
-IC:\raylib\raylib\src ^
-LC:\raylib\raylib\src ^
-lraylib ^
-lopengl32 ^
-lgdi32 ^
-lwinmm

If there are no errors, the executable will be created inside:

build/

===========================================================
STEP 4 - RUN THE GAME
===========================================================

Run:

.\build\Wardogz_II.exe

===========================================================
NOTES
===========================================================

- All source (.c) files belong inside the "src" folder.

- All header (.h) files belong inside the "include" folder.

- Compiled executable files are stored inside the "build" folder.

- Assets such as images, music, sound effects, and fonts are stored inside the "assets" folder.

===========================================================
BATCH FILE COMMANDS
===========================================================

The project includes three batch files for easier compiling
and running from the VS Code terminal.

-----------------------------------------------------------
BUILD ONLY - build.bat
-----------------------------------------------------------

Run:

    .\build.bat

This compiles the Wardogz II source files and creates:

    build\Wardogz_II.exe

-----------------------------------------------------------
RUN ONLY - run.bat
-----------------------------------------------------------

Run:

    .\run.bat

This runs the already compiled game:

    build\Wardogz_II.exe

-----------------------------------------------------------
BUILD AND RUN - build_and_run.bat
-----------------------------------------------------------

Run:

    .\build_and_run.bat

This first compiles the project and, if the build succeeds,
automatically runs Wardogz II.
